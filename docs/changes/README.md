# Change log (for humans & future AI)

每次改动都在本目录新增**一个** Markdown 文件，文件名格式：

```
YYYY-MM-DD-<slug>.md
```

内容请固定包含以下小节，方便后续 AI 快速定位"改了什么、为什么、影响哪些文件、怎么验证"：

```md
# <标题>

- 日期：
- 类型：feat / fix / refactor / style / chore
- 影响面：<页面/模块>

## 动机
为什么改。

## 改动
- 具体改了什么（按文件/模块列）。

## 影响文件
- path/to/file

## 验证
- 如何验证（命令 / 手动步骤 / 已知限制）。

## 备注 / 未决
- 遗留项、可选的后续工作。
```

> 约定：不要修改历史条目；每次新的改动新建文件。
